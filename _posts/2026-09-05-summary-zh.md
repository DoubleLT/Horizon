## [World Labs 发布 Atlas：具备像素级相机控制的多模态世界模型](https://twitter.com/karpathy/status/2095535021146992835) ⭐️ 8.0/10

World Labs 宣布推出 Atlas，称其为世界上首个能够以像素级相机控制生成图像和视频帧的多模态世界模型。该公告被 Andrej Karpathy 转发，引起了广泛关注。 Atlas 代表了 AI 生成内容的重大进步，能够在生成的视频中实现精确的相机控制，这可能彻底改变电影制作、虚拟现实和仿真领域。Karpathy 等知名 AI 人物的背书凸显了其对 AI 社区的潜在影响。 Atlas 能够精确遵循输入的相机参数，包括非平面投影，如 Brown-Conrady 畸变模型和 Kannala-Brandt 鱼眼模型。它还可以将生成的视频重建为点云和高斯泼溅，如一篇博客文章所述。

twitter · karpathy · Sep 3, 15:30

**背景**: 世界模型是学习模拟世界动态的 AI 系统，通常通过生成对未来状态的预测来实现。多模态世界模型整合多种输入类型，如文本、图像和视频，以生成连贯的输出。Atlas 建立在 World Labs 先前的工作（如 Marble）之上，旨在为创作者提供生成逼真、可控视频内容的工具。

## [World Labs 联合创始人宣布可从旧视频重建 3D 场景](https://twitter.com/drfeifei/status/2095928755101503659) ⭐️ 7.0/10

World Labs 联合创始人 Ben Mildenhall 和李飞飞宣布，旧相机胶卷中的视频现在可以重建为 3D 场景，李飞飞的转发强调了这一点。此功能是 World Labs 新推出的 Atlas 世界模型的一部分，该模型可以从稀疏视图生成 3D 高斯溅射。 这一进展可能对计算机视觉和 AR/VR 产生重大影响，使 3D 重建能够从日常视频中实现，可能让用户将个人记忆转化为交互式 3D 体验。这也凸显了空间智能和世界模型的快速进步，这些对于推进机器人和沉浸式媒体至关重要。 World Labs 宣布的 Atlas 模型接受文本、图像、视频和 3D 作为输入，可以生成长达一分钟的相机控制的 1440p 视频，并将场景重建为 3D 高斯溅射。该工具正在进入早期访问阶段，该公告是通过李飞飞的转发发布的，增加了声明的可信度。

twitter · drfeifei · Sep 4, 17:35

**背景**: 从 2D 图像或视频进行 3D 重建是计算机视觉中长期存在的挑战，技术从传统的摄影测量发展到神经辐射场（NeRF），再到最近的 3D 高斯溅射，后者提供更快的渲染和显式 3D 表示。Ben Mildenhall 是该领域的领先研究者，以在 NeRF 和计算摄影方面的工作而闻名，而由李飞飞联合创立的 World Labs 旨在构建能够理解和模拟 3D 环境的大型世界模型。

## [Anthropic 的 ant CLI 新增 'ant apply' 命令，实现声明式代理管理](https://twitter.com/ClaudeDevs/status/2095651107645145538) ⭐️ 7.0/10

Anthropic 的 ClaudeDevs 宣布在 ant CLI 中新增 'ant apply' 命令，使开发者能够将 Claude 托管代理的环境、代理、技能、记忆存储和部署声明为仓库中的文件，并通过 'ant apply' 与 API 资源保持同步。该消息通过官方 ClaudeDevs 账号在推特上发布。 该功能将基础设施即代码（IaC）理念引入 Claude 托管代理，使开发者能够对 AI 代理配置进行版本控制并自动化部署。它简化了复杂代理环境的管理，符合将 AI 资源视为代码的趋势，可能促进依赖 Anthropic 平台的团队更广泛采用。 ant CLI 是 Anthropic 官方的基于 Go 的命令行工具，用于 Claude 平台，提供对 Claude API 的访问以及代理和会话的管理。'ant apply' 专门针对 Claude 托管代理，这是一种预构建、可配置的代理框架，运行在托管基础设施上，适用于长时间运行和异步任务。

twitter · ClaudeDevs · Sep 3, 23:12

**背景**: Claude 托管代理是 Claude 平台上的一项服务，提供运行 Claude 作为自主代理的框架和基础设施，使开发者能够大规模构建和部署 AI 代理。ant CLI 最近发布，为开发者提供对 Claude API 的直接终端访问，而 'ant apply' 扩展了这一点，允许对代理资源进行声明式管理，类似于 Terraform 对云基础设施的管理方式。
