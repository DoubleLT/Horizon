## [微软因成本问题取消内部 Claude Code 许可证](https://twitter.com/ylecun/status/2057782982757257330) ⭐️ 7.0/10

微软本周取消了其内部 Claude Code 许可证，因为基于 token 的计费使得成本难以承受，即使对于拥有几乎无限云资源的公司也是如此。 这凸显了企业采用 AI 编码工具的一个主要障碍：基于 token 的不可预测定价可能迅速超出预算，即使是科技巨头也不例外。这可能会促使企业寻求更具成本效益的替代方案，或要求 Anthropic 等提供商进行定价改革。 Claude Code 按 token 消耗计费，而 Anthropic 从未公布固定费率计划能购买多少计算资源，导致成本估算困难。微软的取消表明，即使拥有庞大的云资源，成本也难以承受。

twitter · ylecun · May 22, 11:17

**背景**: Claude Code 是 Anthropic 开发的 AI 编码助手，采用基于 token 的计费方式，用户按处理的 token 数量付费。基于 token 的定价可能导致成本不可预测，尤其是在大规模使用时，因为每次交互都会消耗 token。微软作为主要的云提供商和 AI 投资者，曾内部使用 Claude Code，但发现成本过高。
