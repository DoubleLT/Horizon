## [ViTs' Dense Detail Lost by Pooling to Single Vector](https://twitter.com/ylecun/status/2080042046056734900) ⭐️ 6.0/10

A tweet by Yann LeCun highlights that pretrained Vision Transformers (ViTs) capture rich, dense visual detail, but most policies discard this information by pooling the patch features into a single vector before acting. This observation points to a common inefficiency in using ViTs for control tasks, where discarding spatial detail may limit performance in tasks requiring fine-grained perception, such as robotics or autonomous driving. The tweet references a trend where policies pool the dense patch features from ViTs (e.g., DINO, V-JEPA) into a single global vector, losing the rich spatial information that ViTs naturally provide.

twitter · ylecun · Jul 22, 21:27

**Background**: Vision Transformers (ViTs) process images by dividing them into patches and extracting features for each patch, resulting in a set of vectors that retain spatial layout. Pooling layers aggregate these vectors into a single representation, often used for classification, but this discards location-specific details that could be valuable for control tasks.
