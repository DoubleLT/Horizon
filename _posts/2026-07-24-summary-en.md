A tweet by Gaoyue Zhou, retweeted by Yann LeCun, highlights that pretrained Vision Transformers (ViTs) capture rich, dense visual detail, but most policies pool this into a single vector before acting, discarding most information. This insight suggests that current policy learning methods may be underutilizing ViT representations, potentially limiting performance in tasks requiring fine-grained visual understanding, such as robotics or autonomous driving. The tweet references ViTs' ability to retain high spatial resolution and semantic information, as demonstrated in works like DINO-ViT, which show that self-supervised ViT features encode powerful high-level information at fine granularity.

twitter · ylecun · Jul 22, 21:27

**Background**: Vision Transformers (ViTs) process images as sequences of patches, producing a set of token embeddings that retain spatial structure. Many downstream policies, especially in reinforcement learning, pool these tokens into a single vector (e.g., using a [CLS] token or average pooling) to obtain a compact representation for decision-making, which can lose spatial details.
