## [微软因成本取消内部 Claude Code 许可](https://twitter.com/ylecun/status/2057782982757257330) ⭐️ 7.0/10

微软本周取消了其内部的 Claude Code 许可，原因是基于 token 的计费导致成本难以承受。 这凸显了大规模使用 AI 编码工具面临的财务挑战，可能影响企业采用决策和整个行业的定价模式。 Claude Code 按 token 消耗计费，而 Anthropic 并未公布固定费率计划能购买多少算力，这使得企业难以管理成本。

twitter · ylecun · May 22, 11:17

**背景**: Claude Code 是 Anthropic 开发的 AI 编码助手，采用基于 token 的计费方式。基于 token 的计费根据处理的 token（文本单位）数量收费，大量使用时成本可能变得高昂。微软此前内部使用 Claude Code，但发现成本难以承受。
