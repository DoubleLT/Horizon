## [编码代理降低技术锁定风险](https://simonwillison.net/2026/May/14/not-so-locked-in/#atom-everything) ⭐️ 6.0/10

一家中型科技公司使用编码代理将其遗留的 iPhone 和 Android 应用重写为 React Native，并指出如果决策有误，未来可以轻松移植回原生。 这一轶事表明，AI 辅助的编码代理正在降低重写软件的成本，使技术选择不再永久，从而减少整个行业的供应商或平台锁定。 该公司选择 React Native 是因为它已有显著改进并满足所有应用需求，但关键洞察在于，借助编码代理，移植回原生现在是一个可行的备选方案。

## [Mitchell Hashimoto：编程语言正变得可互换](https://simonwillison.net/2026/May/14/mitchell-hashimoto/#atom-everything) ⭐️ 6.0/10

HashiCorp 联合创始人 Mitchell Hashimoto 评论了编程语言日益增强的可互换性，以 Bun 从 Zig 移植到 Rust 为例。他认为语言不再是锁定因素，因为 Bun 展示了它可以在大约一两周内切换语言。 这一观点挑战了传统上认为语言选择是长期承诺的看法，暗示现代工具和抽象使语言迁移更加容易。它可能影响开发者和公司评估语言风险及采用策略的方式。 Hashimoto 的推文引用了 Bun 从 Zig 移植到 Rust 的事件，多家来源如 The Register 和 DEV Community 均有报道。此次移植意义重大，因为 Bun 最初使用仍处于测试阶段的 Zig 构建，而转向 Rust 被视为追求稳定性和生态系统成熟度的技术赌注。

rss · Simon Willison · May 14, 22:31

**背景**: Bun 是一个 JavaScript 运行时、包管理器和测试运行器，旨在作为 Node.js 的即插即用替代品。它最初使用 Zig（一种底层系统编程语言）编写。将核心组件移植到 Rust 的决定引发了关于语言选择和可移植性的社区讨论。
