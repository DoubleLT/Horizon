## [单张图片数分钟生成 3D 世界：Image-Blaster](https://twitter.com/drfeifei/status/tweet-2055022392569905411) ⭐️ 8.0/10

World Labs 团队成员 Neilson Koerner-Safrata 发布了 image-blaster，这是一个面向 Claude Code 的开源 3D 生成工具包，能在数分钟内将单张图片转化为包含网格、物理、光照和音频的完整可探索 3D 环境。 该工具大幅降低了 3D 内容创作的门槛，允许从单张照片快速生成沉浸式体验，可能对游戏、VR 和数字孪生产业产生影响。 Image-blaster 作为 Claude Code 的技能集构建，利用 AI 生成包含物理和音频的完整网格 3D 世界。它是开源的，可在 GitHub 上获取，并在 World Labs 的社区展示中有演示。

twitter · Fei-Fei Li · May 14, 20:28

**背景**: 单张图片的 3D 重建是计算机视觉中长期存在的挑战。最近的进展如 TripoSR 和 LRM 可以在数秒内从单张图片生成 3D 网格，但 image-blaster 更进一步，创建了包含交互元素的完整可探索环境。
