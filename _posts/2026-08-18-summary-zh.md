## [极简 AI 代理 Pi 超越 Codex 和 Claude Code](https://twitter.com/tech_shrimp/status/2088907482882265458) ⭐️ 7.0/10

Pi 是一款极简 AI 代理，仅有四个默认工具（读文件、写文件、改文件、运行命令），系统提示词仅 1000 个 token，据称在多项权威基准测试中，其代码质量、工作速度和成本均超越主流代理 Codex 和 Claude Code。推主@tech_shrimp 强调了这一成就，并提供了掌握 Pi 的全面指南。 这一进展挑战了“功能越多性能越好”的假设，表明极致的简洁可以在 AI 编程代理中带来更高的效率。它可能影响未来 AI 代理的设计，使追求高性价比和快速编码辅助的开发者受益。 Pi 被描述为一个极简代理框架，可通过扩展、技能、提示模板和主题进行定制，并打包为包通过 npm 或 git 共享。它带有强大的默认设置，但有意省略了子代理和计划模式等功能，并且没有内置权限系统，默认以用户权限运行。

twitter · tech_shrimp · Aug 16, 08:35

**背景**: 像 OpenAI 的 Codex 和 Anthropic 的 Claude Code 这样的 AI 编程代理，通过自然语言提示帮助开发者生成或编辑代码。它们通常功能丰富，但 Pi 采取了不同的方法，精简到核心功能，推文声称这带来了更好的基准测试结果。“大道至简”的理念反映了简单可能比复杂更有效的哲学。

## [Claude Code CLI 通过延迟 Bun 垃圾回收将 p99 CPU 使用率降低 2 倍](https://twitter.com/ClaudeDevs/status/2089509659090780193) ⭐️ 7.0/10

Claude Code CLI 通过将 Bun 的垃圾回收延迟到进程空闲时执行，将 p99 CPU 使用率降低了 2 倍，避免了运行中途的 CPU 峰值。该消息由 @ClaudeDevs 在 Twitter 上宣布。 这一优化显著提升了这一广泛使用的开发者工具的响应性，减少了交互式编码过程中的延迟峰值。它展示了一种实用的运行时垃圾回收调优方法，可能惠及其他基于 Bun 的应用。 Bun 的垃圾回收器之前按固定定时器运行，导致它在 Claude Code 运行最繁忙时触发并抢占 CPU。该修复将 GC 延迟到进程空闲时执行，这是对延迟敏感应用的常见模式。

twitter · ClaudeDevs · Aug 18, 00:28

**背景**: Bun 是一个 JavaScript 运行时，使用 JavaScriptCore 和 mimalloc 进行内存管理。如果垃圾回收（GC）在不恰当的时间运行，可能会导致性能卡顿。p99（第 99 百分位）是一种性能指标，表示一小部分请求所经历的最差延迟，降低 p99 CPU 使用率有助于确保性能的一致性。

twitter · ylecun · Aug 17, 12:41
