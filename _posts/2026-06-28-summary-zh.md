## [Photoroom 发布 PRX Pixel：开源 7B 像素空间文生图模型](https://twitter.com/ylecun/status/2070603360823071199) ⭐️ 7.0/10

Photoroom 发布了 PRX Pixel，这是一个开源的 7B 参数文生图扩散模型，直接在像素空间生成图像，无需 VAE。该模型已在 Hugging Face 和 GitHub 上以宽松许可证发布。 PRX Pixel 代表了从潜在扩散到像素空间生成的转变，可能减少伪影并提高图像保真度。作为开源模型，它使先进的文生图技术更加普及，并可能激发社区的创新。 该模型使用 Qwen3-VL 文本编码器替代 T5/Gemma，并将生成分辨率输入时间步调制。它经过数亿张图像的预训练，随后进行了监督微调和偏好对齐。

twitter · ylecun · Jun 26, 20:21

**背景**: 大多数文生图模型（如 Stable Diffusion）在潜在空间中运行，使用 VAE 将图像压缩到低维表示后再去噪。像素空间模型直接处理原始 RGB 像素，可以避免压缩伪影，但历史上需要更多计算。PRX Pixel 基于 PRX 变压器扩散框架，并与 PixelDiT 等近期工作相关。
