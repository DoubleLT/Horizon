## [mKernel: Fast Multi-Node, Multi-GPU Fused Kernels Released](https://twitter.com/berkeley_ai/status/2059411345905459410) ⭐️ 7.0/10

UC Berkeley Sky Computing Lab released mKernel, a library of persistent CUDA kernels that fuse intra-node NVLink communication, inter-node RDMA, and dense compute into a single kernel for distributed deep learning. mKernel addresses a key performance bottleneck in distributed training by reducing kernel launch overhead and data movement, potentially accelerating large-scale model training across multiple GPUs and nodes. mKernel uses GPU-initiated RDMA writes via libibverbs, bypassing NCCL and NVSHMEM, and is designed as a small, focused library for high-performance distributed computing.

twitter · berkeley_ai · May 26, 23:08

**Background**: In deep learning, kernel fusion combines multiple GPU operations into a single kernel to improve memory locality and reduce global memory traffic. Distributed training across multiple GPUs and nodes often suffers from communication overhead, which fused kernels like those in mKernel aim to mitigate by overlapping communication with computation.
