## [苏黎世联邦理工的机械手用自己的手指行走](https://twitter.com/lukas_m_ziegler/status/2100156077291557210) ⭐️ 7.0/10

苏黎世联邦理工学院的研究人员开发出一款机械手，它能够用自己的手指在表面上行走，下方没有安装轮子、腿或任何独立的驱动机构。用于抓取物体的同一组手指同时也承担移动功能，使这只手能够自行从一个位置移动到另一个位置。 这表明抓取与移动可以统一在同一个机构中，有望催生更灵活、更紧凑的机器人末端执行器，使其无需单独的移动底座即可自行改变位置。这对探索仿生设计的机器人研究者，以及需要机械臂独立移动的应用场景都具有重要意义。 其核心技术新颖之处在于移动时没有使用独立的驱动机构——手指本身同时提供抓取和行走功能，类似《亚当斯一家》中那只脱离身体的手“Thing”。该演示来自苏黎世联邦理工学院的软体机器人实验室，该实验室此前曾研制出肌腱驱动的拟人机械手，例如具有 17 个自由度的 ORCA 手。

twitter · lukas_m_ziegler · Sep 16, 09:33

**背景**: 机械手通常为操作而设计——即抓取和握持物体——而移动则由单独的机械臂或移动底座负责。肌腱驱动的拟人机械手通过线缆和驱动器来移动关节，模仿人类手部解剖结构；仿生机器人学则致力于复现自然结构以获得灵活性和效率。该项目让同一组手指同时完成两项任务，从而模糊了操作与移动之间的界限。

## [Agility Robotics 发布 Digit 5，采用类人膝盖设计](https://twitter.com/lukas_m_ziegler/status/2099859995332391239) ⭐️ 7.0/10

Agility Robotics 发布了最新款人形机器人 Digit 5，将此前鸵鸟式的向后弯曲腿部替换为朝前的类人膝盖。联合创始人兼首席机器人官 Jonathan Hurst 解释了这一设计变更，同时该版本还升级了电池并采用了更全面的安全架构。 从鸵鸟式腿部转向类人腿部可能提升稳定性、效率和人机交互能力，使 Digit 5 更适合在仓库和工厂中与人类安全协作。这一点尤为重要，因为 Agility Robotics 正筹备通过与 SPAC 合并上市，并扩大与 Amazon、GXO 和 Toyota 等合作伙伴的部署规模。 Digit 5 是 Agility 首款为大规模协作安全作业而设计的人形机器人，可在无需物理安全围栏的情况下靠近人员工作；当有人靠近时，它会停止或跪下。该机器人高 175 厘米，重 65 公斤，配备可更换末端执行器并提升了电池续航。

## [Claude Design、Slides 和 Docs 现已集成到 Claude Code 中](https://twitter.com/ClaudeDevs/status/2100270861555228770) ⭐️ 7.0/10

Anthropic 通过其 @ClaudeDevs 账号宣布，Claude Design、Claude Slides 和 Claude Docs 现在可以在 Claude Code 内部使用，用户能够直接基于仓库中的实际文件和 RFC 生成设计评审演示文稿、UI 原型图和文档。用户可以自行编辑产出内容，或在对话中继续迭代，完成后分享链接。 这一集成将视觉设计与文档工作直接融入 AI 辅助编码流程，开发者与设计师无需在多个工具之间切换，就能把仓库上下文转化为演示文稿或原型图。这表明 Anthropic 正推动 Claude Code 成为端到端的完整工作空间，而不仅仅是基于终端的编码代理，从而加剧了与 Google Gemini 等竞争对手的较量。 该功能以真实的仓库上下文为基础：用户可以让 Claude 指向仓库中的实际文件和 RFC，生成的演示文稿、原型图或文档既可以手动编辑，也可以在后续对话中继续打磨，最后通过链接分享。Claude Design 最初是作为 Anthropic Labs 的产品推出的，用于创建设计稿、原型、幻灯片和单页文档等精美视觉作品。

## [Reach Robotics 展示电动水下机械臂转动阀门](https://twitter.com/lukas_m_ziegler/status/2100153772362039487) ⭐️ 6.0/10

Reach Robotics 展示了一款水下机械臂成功转动阀门，展示了其用于 ROV 搭载机械臂的电动驱动技术。该演示凸显了替代传统液压水下机械臂系统的方案。 电动驱动有望省去液压水下机械臂所需的重型油压动力单元和大型工作级 ROV，使更小、更便携的 ROV 能够执行此前只有潜水员或大型设备才能完成的干预任务。这一转变可能降低成本，并推动海上能源、国防等行业更广泛地开展水下检测与干预作业。 Reach Robotics 提供 Reach Alpha 和 Reach Bravo 等机械臂，其中 Reach Alpha 的额定水深为 300 米，Reach X 则被设计为面向便携式 ROV 的高功率密度紧凑型机械臂。Saab Seaeye 的 eM1-7 等电动水下机械臂具备模块化电动关节，支持高级控制、路径规划和诊断功能。

twitter · lukas_m_ziegler · Sep 16, 09:24

**背景**: 水下机械臂是安装在遥控潜水器（ROV）上的机械臂，用于在水下执行转动阀门、切割和采样等任务。传统上这类机械臂采用液压驱动，需要油压动力单元、较大的质量，以及足以承载系统的工作级 ROV。电动驱动以机电电机和驱动器取代液压油，在重量、效率和控制精度方面具有潜在优势。
