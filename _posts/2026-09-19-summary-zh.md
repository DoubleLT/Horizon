## [MIT 的 FloatForm 机器人小船可自组装成水上结构](https://twitter.com/lukas_m_ziegler/status/2100580140660998171) ⭐️ 8.0/10

来自 MIT CSAIL 和 MIT 可感知城市实验室的研究人员开发了 FloatForm，这是一群边长 21 厘米的方形机器人小船，能够自主连接形成桥梁、平台等水上结构，相关成果已发表在《自然》杂志上。该系统允许这些小船在极少人工干预下组装、拆解并重新组合成新的形态。 这一突破展示了一种实用的自组装模块化机器人形式，有望在城市水道中实现按需基础设施，如临时桥梁或浮动平台。它可能影响未来的城市设计、灾害响应和环境监测，将滨水区域转变为可编程空间。 每个机器人约餐盘大小（21 厘米见方），可以与其他机器人物理连接，形成可重新配置的结构。该系统已发表在《自然》杂志上，涉及极少的人工干预，但具体的技术限制或可扩展性细节在现有信息中尚未完全披露。

twitter · lukas_m_ziegler · Sep 17, 13:38

**背景**: 自组装模块化机器人是群体机器人的一种，许多简单单元通过合作形成更大的结构，通常受蚂蚁群落等生物系统启发。MIT 的可感知城市实验室专注于数字技术如何重塑城市环境，该项目与他们关于自主船只能按需自组织成有用结构的愿景一致。这项研究建立在模块化机器人技术进展的基础上，其中单元可以动态改变其配置。

## [斯坦福 AI 实验室发布 CSBP，加速扩散 LLM 训练](https://twitter.com/StanfordAILab/status/2101020335000998089) ⭐️ 8.0/10

斯坦福 AI 实验室推出了上下文分片块并行（CSBP），这是一种新的分布式并行策略，在 DFlash2 投机解码草稿模型训练上实现了最高 7.59 倍的加速，在另一项任务上实现了 1.61 倍的加速，且加速比随上下文长度增加而提升。 长上下文扩散 LLM 的训练效率是扩展这类模型的主要瓶颈，因此一种加速比随上下文长度增加而提升的并行策略，可能大幅降低计算成本，并支持在更长的序列上进行训练。 CSBP 通过在各 rank 之间对共享的干净序列进行分片，扩展了块并行，这正是其能够扩展到长上下文的原因；报告的速度提升为 DFlash2 草稿模型训练 7.59 倍，另一项任务 1.61 倍。

twitter · StanfordAILab · Sep 18, 18:47

**背景**: 扩散 LLM 通过迭代去噪过程生成文本，而非严格的从左到右解码，这使其在并行生成方面具有吸引力，但也带来了独特的训练挑战。块并行（BP）是一种将工作拆分到不同 rank 的分布式训练技术，而投机解码使用小型草稿模型提出 token，由更大的目标模型并行验证，从而保持输出质量。

## [Claude Code 2.1.277 新增对 AGENTS.md 标准的支持](https://twitter.com/ClaudeDevs/status/2101010592542945673) ⭐️ 7.0/10

从 Claude Code 2.1.277 版本开始，该工具新增了对 AGENTS.md 标准的支持：如果项目文件夹中没有 CLAUDE.md 文件，Claude Code 将改为读取 AGENTS.md 来获取代理指令。 这是一项有意义的互操作性改进，因为同时使用多个 AI 编程代理的开发者现在只需维护一份 AGENTS.md 指令文件，而无需在 CLAUDE.md 等各工具专属文件中重复配置。 该回退机制仅在文件夹中不存在 CLAUDE.md 时生效，因此 CLAUDE.md 仍然具有更高优先级；AGENTS.md 就是普通的 Markdown 文件，采用它无需任何特殊语法或工具。

twitter · ClaudeDevs · Sep 18, 18:08

**背景**: CLAUDE.md 是放在项目根目录的 Markdown 文件，Claude Code 会在每次会话开始时自动读取，相当于一份让代理持续了解代码库的入门脚本。AGENTS.md 是一种简单、开放的格式，作为指导编程代理的统一标准推出，使不同代理工具可以共用同一份指令文件。Claude Code 是 Anthropic 推出的代理式编程工具，运行在终端中，能够理解代码库、编辑文件并通过自然语言执行命令。
