## [VertiGo 机器人利用可倾斜螺旋桨实现垂直爬墙](https://twitter.com/lukas_m_ziegler/status/2101244934028234809) ⭐️ 7.0/10

用户@lukas_m_ziegler 发布推文，展示了由迪士尼研究院苏黎世分部与苏黎世联邦理工学院（ETH Zürich）合作开发的爬墙机器人 VertiGo。该机器人不使用吸盘、磁铁或干性粘合剂，而是依靠两个可倾斜螺旋桨产生的推力，直接沿垂直墙面行驶，并能从地面自动过渡到墙面并跨越障碍。 这种方法绕开了传统粘附式爬墙机器人对表面材质的依赖，有望让巡检、救援或娱乐机器人在更广泛的垂直表面上作业。该推文在社交媒体上获得 974 个点赞和 118 次转发，表明社区对机器人替代性运动策略的高度关注。 VertiGo 采用中央碳纤维底板以减轻重量并最大化推力与重量之比，配备四个轮子（其中一对可转向）和两个各具两个自由度的螺旋桨，用于调节推力方向。该设计在一个为期一年的项目中完成，并由迪士尼研究院于 2015 年 12 月发布。

twitter · lukas_m_ziegler · Sep 19, 09:40

**背景**: 传统爬墙机器人通常依靠吸盘、磁铁或干性粘合剂来附着在表面上，但这些方法对表面材质有特定要求，且难以实现从地面到墙面的过渡。VertiGo 则利用螺旋桨推力将轮子压向墙面，原理类似无人机产生升力，从而能够在地面和墙面行驶。该项目由迪士尼研究院苏黎世分部与苏黎世联邦理工学院合作完成，于 2015 年首次展示。

## [斯坦福 AI 实验室推出 CSBP，加速扩散 LLM 训练](https://twitter.com/StanfordAILab/status/2101020335000998089) ⭐️ 7.0/10

斯坦福 AI 实验室发布了 Context-Sharded Block Parallelism（CSBP），一种面向扩散 LLM 训练的新型分布式并行策略。它使 DFlash2 投机解码草稿模型的训练速度最高提升 7.59 倍，另一场景下提升 1.61 倍，且加速效果随上下文长度增加而增大。 长上下文扩散 LLM 的训练计算成本高昂，而 CSBP 随上下文长度增长的加速效果有望让这类训练更加可行。这对研究扩散语言模型和投机解码的研究者与工程师尤为重要，因为草稿模型的训练往往是瓶颈。 CSBP 在块并行（block parallelism）的基础上，进一步将共享的干净序列分片到各个 rank 上，从而支持长上下文扩展。报告的 7.59 倍和 1.61 倍加速分别针对 DFlash2 草稿模型训练和另一项工作负载，实际收益可能因模型和配置而异。

twitter · StanfordAILab · Sep 18, 18:47

**背景**: 扩散 LLM 通过迭代去噪过程生成文本，而非严格的从左到右解码，在长序列上训练需要将计算分布到多台设备。块并行将序列切分成块并在不同 rank 上处理，但在长上下文下共享的干净序列会成为瓶颈。投机解码通过让小型草稿模型提出 token、再由大模型验证来加速推理，因此高效训练草稿模型对部署至关重要。

## [伯克利 AI 发布 ABC-130K，迄今最大的开源遥操作数据集](https://twitter.com/berkeley_ai/status/2101094946380136927) ⭐️ 7.0/10

伯克利 AI 宣布发布 ABC-130K，称其为迄今最大的开源遥操作数据集，包含 3500 小时、超过 13 万个 episode，该工作已被 CoRL 2026 接收。 大规模开源数据集一直是机器人学习领域的瓶颈，因此这一规模的数据集有望加速行为克隆与具身智能研究，让学术界和工业界实验室共享可复现的基础数据，而不必各自采集私有数据。 根据项目公开材料，ABC-130K 包含约 134,806 个 episode、覆盖 195 项任务，总计约 3,553 小时的双臂操作数据，其中约 43,090 个 episode 带有子任务标注，数据采集自配备两条 6 自由度机械臂的 YAM 双臂平台。

twitter · berkeley_ai · Sep 18, 23:44

**背景**: 遥操作是指由人类操作员实时远程控制机器人，由此产生的关节状态、夹爪动作和视频轨迹通常被用作模仿学习的训练数据。CoRL（Conference on Robot Learning，机器人学习会议）是聚焦机器人与机器学习交叉领域的年度国际会议，CoRL 2026 将在美国得克萨斯州奥斯汀举行。行为克隆是这类数据集通常服务的技术，它训练策略直接从观测中复现演示动作。

## [Claude Code 2.1.277 新增 AGENTS.md 支持，作为 CLAUDE.md 的备选](https://twitter.com/ClaudeDevs/status/2101010592542945673) ⭐️ 7.0/10

从 Claude Code 2.1.277 版本开始，当项目文件夹中没有 CLAUDE.md 时，该工具会改为读取 AGENTS.md 文件，这一消息由 @trq212 发布并被 @ClaudeDevs 转发。这使 Claude Code 兼容其他编码代理已采用的开放 AGENTS.md 约定。 这是一项有意义的互操作性改进：已经为其他 AI 编码代理维护 AGENTS.md 的开发者，不再需要在单独的 CLAUDE.md 文件中重复编写指令。这也表明 Anthropic 愿意遵循社区驱动的跨工具标准，而非强推专有格式，对整个 AI 编码工具生态都有好处。 该回退机制仅在文件夹中不存在 CLAUDE.md 时生效，因此 CLAUDE.md 仍然优先，现有项目不受影响。该设置可以在 Claude Code 的“Project instructions”中更改，此外该版本还包含一些无关的修复，例如对速率受限的 artifact 发布处理。

twitter · ClaudeDevs · Sep 18, 18:08

**背景**: CLAUDE.md 是放在项目根目录的 markdown 文件，Claude Code 会在每次会话开始时读取它，以了解项目特定的上下文，例如构建步骤、测试和约定。AGENTS.md 是一种用于指导编码代理的简单开放格式，作用类似，并已在数千个代码仓库中被采用，部分得益于 GitHub Copilot 的支持。由于不同代理过去期望不同的文件名，开发者往往不得不维护重复的指令文件。
