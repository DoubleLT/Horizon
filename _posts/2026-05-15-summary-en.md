## [Mitchell Hashimoto: Languages Are Becoming Fungible](https://simonwillison.net/2026/May/14/mitchell-hashimoto/#atom-everything) ⭐️ 6.0/10

Mitchell Hashimoto, co-founder of HashiCorp, commented on the increasing fungibility of programming languages, using Bun's port from Zig to Rust as an example. He argued that languages are no longer a source of lock-in, as Bun demonstrated it could switch languages in roughly a week or two. This perspective challenges the traditional view that language choice is a long-term commitment, suggesting that modern tooling and abstractions make language migration easier. It could influence how developers and companies evaluate language risk and adoption strategies. Hashimoto's tweet references Bun's port from Zig to Rust, which has been reported by multiple sources including The Register and DEV Community. The port is significant because Bun was originally built with Zig, a language still in beta, and the move to Rust is seen as a technical bet for stability and ecosystem maturity.

rss · Simon Willison · May 14, 22:31

**Background**: Bun is a JavaScript runtime, package manager, and test runner designed as a drop-in replacement for Node.js. It was initially written in Zig, a low-level systems programming language. The decision to port core components to Rust has sparked community discussion about language choice and portability.
