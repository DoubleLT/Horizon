## [Claude Code CLI Cuts p99 CPU Usage by 2x via Bun GC Idle Scheduling](https://twitter.com/ClaudeDevs/status/2089509659090780193) ⭐️ 7.0/10

Anthropic's Claude Code CLI has reduced p99 CPU usage by 2x by deferring Bun's garbage collector to run only when the process is idle, instead of on a fixed timer. This change prevents GC from stealing CPU during the busiest parts of a coding session. This optimization significantly improves the responsiveness and efficiency of a widely-used AI coding tool, directly benefiting developers who rely on Claude Code for daily tasks. It also highlights the importance of runtime-level tuning in AI-assisted development environments, potentially influencing how other tools manage background processes. The fix involves changing Bun's garbage collection scheduling from a fixed timer to an idle-time trigger, ensuring GC runs only when the process is not actively processing requests. The improvement is measured at the p99 percentile, indicating a reduction in worst-case CPU spikes, which is critical for maintaining low latency in interactive tools.

twitter · ClaudeDevs · Aug 18, 00:28

**Background**: Bun is a JavaScript runtime that includes a garbage collector (GC) to automatically manage memory. In Claude Code CLI, Bun's GC previously ran on a fixed timer, which could interrupt CPU-intensive operations. By deferring GC to idle periods, the tool avoids performance degradation during peak usage. This optimization is part of ongoing efforts to enhance the performance of AI coding assistants.
