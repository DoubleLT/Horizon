## [Rolling-Bonxai: Memory-Efficient Mapping for Large-Scale Robot Exploration](https://twitter.com/lukas_m_ziegler/status/2073106046940327985) ⭐️ 7.0/10

Rolling-Bonxai is a rolling voxel grid implementation of Bonxai that avoids storing the entire map in memory, preventing RAM exhaustion during large-area exploration by robots. It is designed for ROS 2 and requires a point cloud source such as a depth camera or LiDAR. This addresses a critical memory bottleneck in large-scale robotic mapping, enabling drones and ground robots to explore entire cities or warehouses without running out of RAM. It makes long-duration autonomous missions more feasible and cost-effective. Rolling-Bonxai is built on Bonxai, a fast hierarchical sparse voxel grid, and only keeps a sliding window of recent voxels in memory. The method is open-source and available on GitHub under ROS 2.

twitter · lukas_m_ziegler · Jul 3, 18:06

**Background**: Robotic mapping often uses voxel grids to represent 3D space, but storing a full grid for large areas consumes excessive RAM. Bonxai is a hierarchical sparse voxel grid that reduces memory usage, and Rolling-Bonxai extends it by discarding old regions as the robot moves, similar to a sliding window approach.

Synthetic data and reinforcement learning have recently been applied to automate GPU kernel generation for other languages like Triton.
