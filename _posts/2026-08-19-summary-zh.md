## [Claude Code CLI 通过 Bun 垃圾回收空闲调度将 p99 CPU 使用率降低 2 倍](https://twitter.com/ClaudeDevs/status/2089509659090780193) ⭐️ 7.0/10

Anthropic 的 Claude Code CLI 通过将 Bun 的垃圾回收器改为仅在进程空闲时运行（而非固定定时器），将 p99 CPU 使用率降低了 2 倍。这一改动避免了在编码会话最繁忙时 GC 抢占 CPU。 这一优化显著提升了广泛使用的 AI 编码工具的响应速度和效率，直接惠及依赖 Claude Code 进行日常开发的开发者。它也凸显了在 AI 辅助开发环境中进行运行时级调优的重要性，可能影响其他工具管理后台进程的方式。 该修复将 Bun 的垃圾回收调度从固定定时器改为空闲触发，确保仅在进程不活跃处理请求时运行 GC。改进以 p99 百分位衡量，表明最坏情况下的 CPU 峰值降低，这对保持交互式工具的低延迟至关重要。

twitter · ClaudeDevs · Aug 18, 00:28

**背景**: Bun 是一个 JavaScript 运行时，包含垃圾回收器（GC）来自动管理内存。在 Claude Code CLI 中，Bun 的 GC 之前按固定定时器运行，可能会中断 CPU 密集型操作。通过将 GC 推迟到空闲时段，该工具避免了高峰使用期间的性能下降。这一优化是持续提升 AI 编码助手性能的努力的一部分。
