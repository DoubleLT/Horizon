## [Stanford AI Lab Unveils CSBP for Faster Diffusion LLM Training](https://twitter.com/StanfordAILab/status/2101020335000998089) ⭐️ 8.0/10

Stanford AI Lab introduced Context-Sharded Block Parallelism (CSBP), a new distributed parallelism strategy that achieves up to 7.59x faster training for DFlash2 speculative decoding drafter models and 1.61x speedup on another workload, with gains that grow as context length increases. Training efficiency for long-context diffusion LLMs is a major bottleneck in scaling these models, so a parallelism strategy whose gains increase with context length could substantially reduce compute costs and enable training on much longer sequences. CSBP extends block parallelism by also sharding the shared clean sequence across ranks, which is what allows it to scale to long contexts; the reported speedups are 7.59x for DFlash2 drafter training and 1.61x for a second workload.

twitter · StanfordAILab · Sep 18, 18:47

**Background**: Diffusion LLMs generate text through an iterative denoising process rather than strictly left-to-right decoding, which makes them attractive for parallel generation but also creates distinct training challenges. Block parallelism (BP) is a distributed training technique that splits work across ranks, and speculative decoding uses a small drafter model to propose tokens that a larger target model verifies in parallel, preserving output quality.

This is a meaningful interoperability improvement, since developers who use multiple AI coding agents can now maintain a single AGENTS.md instruction file instead of duplicating configuration across tool-specific files like CLAUDE.md. The fallback only applies when no CLAUDE.md exists in a folder, so CLAUDE.md still takes precedence; AGENTS.md is plain Markdown, meaning no special syntax or tooling is required to adopt it.

**Background**: CLAUDE.md is a Markdown file placed at a project's root that Claude Code reads automatically at the start of each session, acting like an onboarding script that gives the agent persistent context about the codebase. AGENTS.md is a simple, open format introduced as a unified standard for guiding coding agents, so different agent tools can share one instruction file. Claude Code is Anthropic's agentic coding tool that runs in the terminal, understands codebases, edits files, and executes commands via natural language.
