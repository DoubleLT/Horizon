## [AsymFlow Proposes Low-Rank Velocity for Pixel Generation](https://twitter.com/unknown/status/2055080480173932789) ⭐️ 6.0/10

A new paper titled AsymFlow argues that JiT x0-prediction is insufficient for pixel generation and proposes keeping the velocity in a low-rank subspace instead. This work achieves a state-of-the-art 1.57 FID on ImageNet in pixel space, making it the best pixel flow model to date, which could advance generative modeling for images. The model is called Asymmetric Flow (AsymFlow) and uses a rank-asymmetric flow parameterization. The official implementation is available on GitHub under the LakonLab repository.

twitter · unknown · May 15, 00:19

**Background**: Flow-based generative models learn to transform a simple distribution into complex data via invertible mappings. JiT (Joint Training) x0-prediction is a technique that predicts the original data point directly, but AsymFlow finds it insufficient for high-quality pixel generation. Low-rank subspace methods reduce dimensionality by representing data in a lower-dimensional space, which can improve efficiency and quality.
