## [Claude Code CLI cuts p99 CPU usage by 2x with Bun GC deferral](https://twitter.com/ClaudeDevs/status/2089509659090780193) ⭐️ 7.0/10

Claude Code CLI has reduced p99 CPU usage by 2x by deferring Bun's garbage collector until the process is idle, preventing mid-turn CPU spikes. The change was announced on Twitter by @ClaudeDevs. This optimization significantly improves the responsiveness of a widely-used developer tool, reducing latency spikes during interactive coding sessions. It demonstrates a practical approach to tuning runtime garbage collection that could benefit other Bun-based applications. Bun's garbage collector previously ran on a fixed timer, causing it to trigger during the busiest parts of a Claude Code turn and steal CPU. The fix defers GC until the process is idle, which is a common pattern for latency-sensitive applications.

twitter · ClaudeDevs · Aug 18, 00:28

**Background**: Bun is a JavaScript runtime that uses JavaScriptCore and mimalloc for memory management. Garbage collection (GC) can cause performance hiccups if it runs at inopportune times. p99 (99th percentile) is a performance metric that indicates the worst-case latency experienced by a small fraction of requests, and reducing p99 CPU usage helps ensure consistent performance.
