This result suggests that JEPA-based approaches can surpass dominant contrastive methods like CLIP and SigLIP when scaled, potentially shifting the paradigm in vision-language pretraining. The method uses a sigmoid-based regularizer (SIGReg) within the JEPA framework, and the experiments scale from CC12M to the larger DataComp-L dataset. The tweet by Yann LeCun highlights the significance.

twitter · ylecun · Jul 2, 16:28

**Background**: JEPA (Joint Embedding Predictive Architecture) is a self-supervised learning approach that predicts representations of parts of an input from other parts, without using labels or negative examples. CLIP and SigLIP are contrastive vision-language models that align image and text embeddings using contrastive loss; SigLIP uses a sigmoid loss instead of softmax. SIGReg is a regularizer designed to prevent collapse in self-supervised learning.

If adopted, it could accelerate the development of robots that better align with human values and perform complex tasks more reliably. Freeform Preference Learning (FPL), introduced in a recent arXiv paper, lets annotators define preference axes such as speed, safety, or quality, and provide relative comparisons along each axis. Preference learning uses human comparisons of robot trajectories to infer rewards, but traditional methods ask for a single overall preference, discarding nuanced information. Freeform Preference Learning aims to capture richer feedback by allowing annotators to specify preferences along multiple natural-language dimensions.

## [Rolling-Bonxai: Efficient Memory for Large-Scale Robot Mapping](https://twitter.com/lukas_m_ziegler/status/2073106046940327985) ⭐️ 5.0/10

Rolling-Bonxai is a new method for efficient memory management in large-scale robot mapping that avoids storing the entire map by using a rolling voxel grid with chunking. This approach enables drones and ground robots to map massive areas like cities or warehouses without exhausting RAM, making long-duration autonomous exploration more feasible.
