## [Async VLA inference breaks Markov assumption for RL fine-tuning](https://twitter.com/berkeley_ai/status/2102237200121549137) ⭐️ 6.0/10

A researcher (ehharrison4, retweeted by @berkeley_ai) pointed out that running vision-language-action (VLA) model inference asynchronously reduces inference delay, but in doing so it breaks the Markovian assumption that reinforcement learning (RL) fine-tuning relies on. The tweet frames this as a fundamental trade-off between low-latency robot control and RL-compatible training. As VLA models grow larger, asynchronous inference has become a common way to keep robots moving without waiting for the policy to compute the next action chunk, so this observation matters for anyone trying to combine real-time VLA deployment with RL fine-tuning. If the Markov property no longer holds, standard RL algorithms may learn from temporally misaligned state-action pairs, potentially degrading policy quality. In asynchronous inference, action prediction is decoupled from action execution, so the robot and environment continue to evolve while the model computes, creating a temporal misalignment between the prediction and execution intervals. This means the state observed when an action is finally executed may differ from the state the policy conditioned on, violating the assumption that the next state depends only on the current state and action.

twitter · berkeley_ai · Sep 22, 03:23

**Background**: Vision-language-action (VLA) models are multimodal foundation models that take an image or video of the robot's surroundings plus a text instruction and directly output low-level robot actions; the concept was pioneered by Google DeepMind's RT-2 in July 2023. Reinforcement learning typically assumes the Markov property, meaning the distribution over the next state is conditionally independent of all previous states and actions given the current state and action. Asynchronous inference decouples action prediction from action execution so robots can maintain continuous motion without 'wait-for-inference' lags, which is increasingly important as model sizes grow.
